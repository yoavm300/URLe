# Bootcamp Context

Target Audience:
Junior DevOps engineers with basic Linux Python cloud and networking knowledge.

Environment:
- Labs run locally using Docker and kind.
- Later modules use AWS.
- Students do not have enterprise access.

Course Duration:
12 weeks.

Teaching Style:
Theory first, hands-on second.
Production-focused.
Encourage debugging mindset.

Depth Level:
Intermediate but beginner-friendly.
